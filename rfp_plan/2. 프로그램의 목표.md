# 2. 프로그램의 목표

## 2.1 사업 비전

한국선급(KR)의 대용량 엔지니어링 데이터를 체계적으로 관리·처리·분석할 수 있는 **웹 기반 통합 플랫폼**을 구축하여, 업무 효율성 향상과 데이터 기반 의사결정 체계를 확립한다. 특히, 선급 업무에서 발생하는 **정형·비정형·멀티모달 데이터 전체**를 포괄적으로 수집·저장·버전 관리하고, 이를 **정형 데이터로 추출·변환하여 분석 및 예측 모델 생성**까지 연결하는 엔드투엔드 데이터 파이프라인을 지향한다.

---

## 2.2 핵심 목표

### 목표 1. 비정형·멀티모달 데이터 통합 수집·저장 체계 구축
- 선급 업무에서 발생하는 **모든 유형의 데이터**를 수집·저장할 수 있는 통합 저장소 구현
  - **정형 데이터**: 해석 결과, 수치 데이터, DB 레코드
  - **비정형 데이터**: 보고서(PDF/문서), 이미지, 스캔 데이터, 로그 파일
  - **멀티모달 데이터**: 3D 모델, 도면, 사진, 영상, 센서 데이터 등
- 서버 저장소 기반 자동 수집과 수동 업로드를 병행하여 데이터 유입 경로 일원화
- 메타데이터 추출·색인을 통한 **고속 검색 및 필터링** 체계 확보
- 데이터 유형에 무관하게 **통일된 방식으로 등록·조회·관리** 가능한 범용 구조 설계

### 목표 2. HullScan / Frame3D 프로그램 버전 관리 (1차 적용 대상)
- 1차 적용 대상으로 **HullScan**(선체 스캔/검사)과 **Frame3D**(3D 구조 해석) 프로그램의 입출력 데이터 버전 관리 수행
- 프로그램별 실행 파일, 입력 파라미터, 출력 결과, 설정 파일 등을 **버전 단위로 추적·관리**
- **버전 히스토리 자체도 데이터로 저장**하여, 변경 이력·비교·롤백이 가능한 구조
- 향후 선급 내 다른 프로그램으로 버전 관리 대상을 확장할 수 있는 범용 프레임워크 설계

### 목표 3. 비정형 → 정형 데이터 추출 파이프라인
- 수집된 멀티모달·비정형 데이터로부터 **정형 데이터를 자동·반자동으로 추출·변환**하는 파이프라인 제공
  - 보고서(PDF/문서) → 테이블·수치 데이터 추출
  - 3D 모델·도면 → 치수·형상 파라미터 추출
  - 이미지·스캔 데이터 → 결함 위치·크기·유형 정량화
  - 로그·센서 데이터 → 시계열 정형 데이터 변환
- 추출 품질 점수 기반 자동/반자동/수동 모드 분기
- 추출기 플러그인 아키텍처로 신규 데이터 유형 확장 가능

### 목표 4. 데이터 분석 환경 (EDA)
- 추출된 정형 데이터를 기반으로 **웹 기반 탐색적 데이터 분석 환경** 제공
  - 통계 요약, 분포 시각화, 상관 분석, 이상치 탐지
  - 시계열 분석 (추세, 계절성, 자기상관)
  - 사용자 정의 분석 뷰: 필터링·그룹핑·피벗 등 다차원 분석
- 프로젝트/기간/버전/대상 간 **비교 분석** 기능
- 데이터 프로파일링 자동 리포트 및 분석 세션 저장·공유

### 목표 5. 예측 모델 생성·관리
- 축적된 정형 데이터를 학습 데이터로 활용하여 **예측 모델 생성** (회귀, 분류, 시계열 예측 등)
- **Model Registry**를 통한 모델 버전 관리, 학습 이력 추적, 성능 지표 비교
- 생성된 모델을 통한 **신규 데이터 예측·추론 실행** 및 결과 시각화
- 모델 모니터링: 데이터 드리프트 감지, 성능 저하 알림, 재학습 권고
- **엔드투엔드 흐름**: 수집(3.01) → 추출(3.03) → 분석(3.04) → 학습 → 예측

### 목표 6. 작업 실행 자동화 및 자원 최적화
- 등록된 데이터에 대한 **순차/병렬 작업 실행, 배치 스케줄링, 작업 큐 관리** 제공
- 라이선스 및 하드웨어 자원의 실시간 모니터링과 **잔여 자원 가시화**
- 우선순위 기반 대기열 정책으로 조직·프로젝트 단위 자원 배분 최적화

### 목표 7. 결과 추적·재현·시각화
- 실행 결과의 **이력 관리(입력/파라미터/버전/시간)** 및 재현성 보장
- 다수 결과의 경향·통계를 **그래프·대시보드**로 시각화
- 사용자 정의 시각화 뷰를 통한 맞춤형 분석 환경 제공

### 목표 8. 웹 기반 3D 모델 조회 환경 제공
- 별도 소프트웨어 설치 없이 **웹 브라우저에서 3D 모델 조회**
- 대용량 모델에 대한 성능 최적화(LOD/캐시/스트리밍) 적용

### 목표 9. 다중 조직·고객 지원 체계 확립
- **SSO 연동 및 역할 기반 권한 관리**(관리자/일반/고객사)
- 조직(고객)별 데이터 분리, 프로젝트 단위 접근 제어
- 고객사별 라이선스 정책·사용량 관리 및 문의/지원 프로세스 연계

## 2.3 시스템 품질 목표

| 품질 속성 | 목표 |
|-----------|------|
| **확장성** | 사용자 증가 및 데이터 축적에 대응하는 수평/수직 확장 구조 |
| **안정성** | 대용량 파일 무결성 검증, 재시도/복구 메커니즘, 장애 격리 |
| **보안성** | 인증/인가, 전송·저장 암호화, 감사 로그, 개인정보보호 준수 |
| **가용성** | 모니터링·경보 체계, 백업/복구(RPO/RTO), 재해 복구 방안 |
| **호환성** | 주요 브라우저 크로스 브라우징, OS 업데이트 호환성 유지 |
| **유지보수성** | 모듈화·계층화 구조, 표준 API 기반 연계, 컨테이너 배포 |

## 2.4 아키텍처 목표

```
┌──────────────────────────────────────────────────────────┐
│                    사용자 (웹 브라우저)                     │
├──────────────────────────────────────────────────────────┤
│  Frontend: 컴포넌트 기반 UI / HTML5 웹 표준 / 3D Viewer    │
├──────────────────────────────────────────────────────────┤
│  Backend: REST API / 비즈니스 로직 / 작업 큐·스케줄러       │
├──────────────────────────────────────────────────────────┤
│  데이터 파이프라인:                                        │
│  멀티모달 수집 → 정형 추출 → 분석(EDA) → 모델 학습 → 예측   │
├─────────────────┬──────────────────┬─────────────────────┤
│  DB 서버         │  주 저장소        │  보조 저장소          │
│  메타/이력/로그   │  원본 데이터      │  임시/작업 공간       │
│  모델/학습 이력   │  (Hot/Cool 계층)  │  추출 정형 데이터     │
├─────────────────┴──────────────────┴─────────────────────┤
│  인프라: 컨테이너 기반 / CI·CD 자동화 / 클라우드 우선        │
└──────────────────────────────────────────────────────────┘
```

- **프론트엔드/백엔드/DB 3-tier 분리** 및 표준 API 중심 연계
- **컨테이너 기반 배포**로 환경 독립성 및 배포 일관성 확보
- **CI/CD 파이프라인** 자동화(빌드/테스트/배포/롤백)
- **클라우드 우선**, 온프레미스 병행 운영 가능한 유연한 구조

## 2.5 기대 효과

| 구분 | 기대 효과 |
|------|-----------|
| **데이터 통합** | 정형·비정형·멀티모달 데이터를 단일 플랫폼에서 통합 관리하여 데이터 사일로 해소 |
| **버전 관리** | HullScan/Frame3D 시작으로 전사 프로그램의 데이터 버전 추적·재현·롤백 체계 확보 |
| **분석·예측** | 비정형 데이터의 정형화 → 분석 → 예측 모델 생성으로 데이터 활용 가치 극대화 |
| **업무 효율** | 데이터 검색·실행·결과 확인을 단일 플랫폼에서 처리하여 업무 시간 단축 |
| **자원 활용** | 라이선스·하드웨어 자원의 가시화 및 자동 배분으로 유휴 자원 최소화 |
| **품질 향상** | 실행 이력·버전 관리를 통한 결과 재현성 확보 및 품질 추적 |
| **협업 강화** | 조직·프로젝트 단위 데이터 공유 및 권한 관리로 체계적 협업 지원 |
| **의사결정** | 대시보드·통계 시각화를 통한 데이터 기반 의사결정 역량 강화 |
| **운영 안정** | 모니터링·알림·백업/복구 체계를 통한 서비스 연속성 보장 |
