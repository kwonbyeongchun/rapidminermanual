# 3.09 다중 조직·고객 지원 체계 - 구현 방법론

## 3.09.1 개요

SSO 연동 및 역할 기반 권한 관리, 조직(고객)별 데이터 분리, 프로젝트 단위 접근 제어, 고객사별 라이선스 정책·사용량 관리, 문의/지원 프로세스를 구현한다.


### 데이터 격리 방식: Row-Level Security (RLS)

```sql
-- 모든 데이터 테이블에 organization_id 포함
-- PostgreSQL RLS 정책으로 자동 격리

ALTER TABLE projects ENABLE ROW LEVEL SECURITY;

CREATE POLICY org_isolation ON projects
  USING (organization_id = current_setting('app.current_org_id')::UUID);

-- 사용자 요청 시 세션에 조직 ID 자동 설정
-- → 쿼리에 WHERE 절 없이도 자동으로 자기 조직 데이터만 조회
```

## 3.09.3 인증·인가 체계

### SSO 연동

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 사용자    │ ──→ │ 플랫폼    │ ──→ │ IdP      │
│ (브라우저)│     │ (SP)     │     │ (SSO서버) │
└──────────┘     └──────────┘     └──────────┘
                      │
              ┌───────┴───────┐
              │ 지원 프로토콜   │
              │ - SAML 2.0    │
              │ - OAuth 2.0   │
              │ - OIDC        │
              │ - LDAP/AD     │
              └───────────────┘
```

- **1차**: 한국선급 내부 계정 체계(AD/LDAP) 연동
- **2차**: 외부 고객사 SSO 연동 (SAML 2.0 / OIDC)
- **폴백**: 플랫폼 자체 계정 (SSO 미지원 고객용)

### 역할 기반 접근 제어 (RBAC)

| 역할 | 범위 | 주요 권한 |
|------|------|----------|
| **시스템 관리자** | 전체 플랫폼 | 모든 조직·사용자·정책 관리 |
| **조직 관리자** | 소속 조직 | 조직 내 사용자·프로젝트·정책 관리 |
| **프로젝트 관리자** | 특정 프로젝트 | 프로젝트 설정, 멤버 관리, 데이터 관리 |
| **분석가** | 할당된 프로젝트 | 데이터 조회, 실행, 분석, 내보내기 |
| **뷰어** | 할당된 프로젝트 | 읽기 전용 (데이터 조회, 결과 확인) |
| **고객 사용자** | 고객 조직 내 | 조직 관리자가 부여한 권한 범위 |

## 3.09.5 고객사별 라이선스·사용량 관리

### 라이선스 정책 관리

```
┌────────────────────────────────────────────────┐
│          고객사 라이선스 관리 화면                  │
├────────────────────────────────────────────────┤
│                                                │
│  고객사 A (조선소)                                │
│  ├─ 사용자 상한: 10명 (현재 7명)                  │
│  ├─ HullScan 라이선스: 3개 (잔여 1개)             │
│  ├─ Frame3D 라이선스: 2개 (잔여 2개)              │
│  ├─ 저장소 할당: 500GB (사용 320GB, 64%)          │
│  ├─ 월 실행 한도: 500회 (사용 312회, 62%)          │
│  └─ 계약 기간: 2024.01 ~ 2025.12                │
│                                                │
│  고객사 B (해운사)                                │
│  ├─ 사용자 상한: 5명 (현재 3명)                   │
│  ├─ ...                                        │
└────────────────────────────────────────────────┘
```

### 사용량 모니터링

```sql
-- 조직별 사용량 집계
CREATE TABLE usage_metrics (
  id              UUID PRIMARY KEY,
  organization_id UUID NOT NULL,
  metric_date     DATE NOT NULL,
  metric_type     VARCHAR(50),    -- 'login' | 'execution' | 'storage' | 'download'
  count           INTEGER,
  detail          JSONB,          -- 상세 내역
  UNIQUE(organization_id, metric_date, metric_type)
);
```

수집 항목:
- **접속 통계**: 일별 로그인 수, 활성 사용자 수, 세션 시간
- **실행 통계**: 프로그램별 실행 횟수, 성공률, 평균 소요 시간
- **저장소 사용량**: 업로드/다운로드량, 총 사용량 추이
- **API 호출량**: 외부 연계 API 사용량

## 3.09.6 감사 로그

### 기록 대상 이벤트

| 이벤트 | 기록 항목 |
|--------|----------|
| 로그인/로그아웃 | 시각, IP, 브라우저, 성공/실패 |
| 권한 변경 | 대상 사용자, 이전/이후 역할, 변경자 |
| 데이터 접근 | 파일 조회/다운로드, 대상 파일, 접근자 |
| 작업 실행 | 프로그램, 입력 데이터, 실행자, 결과 |
| 설정 변경 | 변경 항목, 이전/이후 값, 변경자 |
| 데이터 삭제 | 삭제 대상, 삭제자, 삭제 사유 |

### 감사 로그 조회 UI
- 기간/이벤트 유형/사용자/IP별 필터링
- 실시간 로그 스트림 (관리자)
- CSV 내보내기 (감사 보고용)
- 보존 기간: 최소 2년 (정책에 따라 조정)

## 3.09.7 문의/지원 프로세스

### 티켓 시스템 연계

```
사용자                      플랫폼                    담당자
  │                          │                         │
  ├─ "문의하기" 클릭 ──────→  │                         │
  │                          ├─ 티켓 자동 생성           │
  │                          │  (유형/우선순위 분류)      │
  │                          ├─ 파일/스크린샷 첨부 ─────→ │
  │                          │                         ├─ 담당자 배정
  │  ←── 접수 확인 알림 ──────┤                         │
  │                          │  ←── 답변/조치 ──────────┤
  │  ←── 답변 알림 ──────────┤                         │
  │                          │                         │
  ├─ 추가 문의/종결 ─────────→│                         │
```

### 구현 방식
- **내장 간이 티켓**: 플랫폼 내 기본 문의 기능 (DB 기반)
- **외부 연동**: Jira Service Management / Zendesk 등 API 연동 (선택)
- **데이터 첨부**: 문의 관련 데이터·실행 로그를 자동 첨부 (권한 범위 내)
- **FAQ/도움말**: 자주 묻는 질문 + 온라인 매뉴얼 제공

## 3.09.8 구현 기술 스택

| 구성 요소 | 기술 | 역할 |
|----------|------|------|
| **인증** | Keycloak 또는 Auth0 | SSO/OIDC/SAML, 사용자 관리 |
| **인가** | CASL (프론트) + 미들웨어 (백엔드) | RBAC 권한 체크 |
| **데이터 격리** | PostgreSQL RLS | 조직 간 데이터 격리 |
| **감사 로그** | 전용 audit 테이블 + 비동기 기록 | 변조 방지 로그 |
| **사용량 집계** | Cron Job + 집계 테이블 | 일별/월별 사용량 통계 |
| **티켓** | 내장 모듈 또는 외부 API 연동 | 문의/지원 관리 |
