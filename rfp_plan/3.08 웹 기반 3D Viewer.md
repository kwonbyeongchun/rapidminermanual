# 3.08 웹 기반 3D 모델 조회 환경 - 구현 방법론

## 3.08.1 개요

별도 소프트웨어 설치 없이 웹 브라우저에서 3D 모델을 조회(편집 불가)할 수 있는 환경을 제공한다. 대용량 모델에 대한 성능 최적화(LOD/캐시/스트리밍)를 적용한다.

---

## 3.08.3 지원 파일 포맷

| 포맷 | 용도 | 처리 방식 |
|------|------|----------|
| **STEP (.step/.stp)** | CAD 교환 표준 | 서버 변환 → glTF |
| **IGES (.igs/.iges)** | CAD 교환 | 서버 변환 → glTF |
| **STL (.stl)** | 메시 모델 | 직접 로드 또는 glTF 변환 |
| **OBJ (.obj)** | 범용 3D | Three.js 직접 로드 |
| **glTF/GLB (.gltf/.glb)** | 웹 3D 표준 | 직접 렌더링 (최적 포맷) |
| **VTK (.vtk/.vtp)** | 해석 결과 시각화 | vtk.js 또는 변환 후 렌더링 |
| **IFC (.ifc)** | BIM 모델 | web-ifc 라이브러리 |

## 3.08.4 조회 기능

### 뷰 조작
| 기능 | 조작 | 구현 |
|------|------|------|
| **회전 (Orbit)** | 마우스 좌클릭 드래그 | OrbitControls |
| **이동 (Pan)** | 마우스 우클릭 드래그 | OrbitControls |
| **확대/축소** | 마우스 휠 | OrbitControls |
| **맞춤 보기** | 더블클릭 / Fit 버튼 | boundingBox 기반 카메라 조정 |
| **표준 뷰** | 전면/후면/좌/우/상/하 버튼 | 카메라 프리셋 위치 |

### 모델 탐색
| 기능 | 설명 |
|------|------|
| **파트 트리** | 좌측 패널에 모델 계층 구조 표시, 클릭 시 해당 파트 하이라이트 |
| **파트 선택** | 클릭 시 파트 정보(이름, 치수, 재질) 속성 패널에 표시 |
| **표시/숨김** | 파트별 가시성 토글 (복잡한 모델에서 관심 영역만 조회) |
| **투명도** | 선택 파트 투명도 조절 (내부 구조 확인) |
| **단면 보기** | 절단면 설정으로 내부 단면 조회 (Clipping Plane) |
| **측정 도구** | 점간 거리, 면적 측정 (조회 전용, 편집 불가) |

### 결과 오버레이 (해석 결과 시각화)
- Frame3D 등 해석 결과를 3D 모델 위에 **컬러맵으로 오버레이**
- 응력/변위/온도 등 물리량별 컬러 스케일 표시
- 범례(Legend) + 최대/최소값 표시

## 3.08.5 대용량 모델 성능 최적화

### A. 서버 사전 변환

```
원본 업로드 시 (비동기 처리):
  1. 원본 저장 (STEP/IGES)
  2. glTF/GLB 변환 (OpenCASCADE → glTF 변환 파이프라인)
  3. LOD 레벨 생성:
     ├─ LOD 0: 원본 해상도 (Full Detail)
     ├─ LOD 1: 50% 간소화 (Medium)
     ├─ LOD 2: 20% 간소화 (Low)
     └─ LOD 3: 5% 간소화 (Preview)
  4. 썸네일 이미지 생성 (PNG)
  5. 바운딩 박스·파트 트리 메타데이터 추출
```

### B. LOD (Level of Detail) 전략

```
카메라 거리에 따른 LOD 자동 전환:

  가까움        ←─────────────────→       멀리
  LOD 0 (Full)  LOD 1 (Medium)  LOD 2 (Low)  LOD 3 (Preview)
  100% 정점     50% 정점        20% 정점      5% 정점
```

- 화면에 보이는 영역(Frustum) 내 오브젝트만 렌더링
- 카메라 거리에 따라 자동 LOD 전환
- 파트별 독립 LOD 적용 (관심 파트만 고해상도)

### C. 프로그레시브 로딩 (스트리밍)

```
초기 로딩:
  1단계 (0~2초): LOD 3 (5%) 로드 → 즉시 화면 표시
  2단계 (2~5초): LOD 2 (20%) 점진 교체
  3단계 (5~15초): LOD 1 (50%) 점진 교체
  사용자 줌인 시: LOD 0 (100%) 해당 영역만 로드
```

### D. 캐싱 전략

| 계층 | 캐시 대상 | 유효 기간 |
|------|----------|----------|
| **브라우저 캐시** | 변환된 glTF, 텍스처 | 모델 해시 기반 (영구) |
| **CDN 캐시** | LOD 모델, 썸네일 | 24시간 |
| **서버 캐시** | 변환 결과, 메타데이터 | 모델 변경 시까지 |

### E. 성능 목표

| 지표 | 목표 |
|------|------|
| 초기 표시 시간 (최초 뷰) | < 3초 |
| 인터랙션 프레임레이트 | 30fps 이상 |
| 최대 지원 모델 크기 | 500MB+ (원본 기준) |
| 메모리 사용량 | < 2GB (브라우저) |

## 3.08.6 구현 기술 스택

| 구성 요소 | 기술 | 역할 |
|----------|------|------|
| **3D 렌더링** | Three.js | WebGL 기반 3D 렌더링 엔진 |
| **CAD 변환** | OpenCASCADE (OCCT) | STEP/IGES → glTF 변환 |
| **메시 간소화** | meshoptimizer / OpenMeshEffects | LOD 생성 |
| **해석 시각화** | vtk.js (필요 시) | 해석 결과 컬러맵 |
| **React 통합** | @react-three/fiber | Three.js React 바인딩 |
| **UI 컨트롤** | @react-three/drei | 카메라·조명·헬퍼 |
