# 3.04 데이터 분석 환경 (EDA) - 구현 방법론

## 3.04.1 개요

추출된 정형 데이터를 기반으로 탐색적 데이터 분석(Exploratory Data Analysis) 환경을 제공한다. 사용자가 웹 기반 인터페이스에서 통계 요약, 시각화, 상관 분석, 이상치 탐지, 다차원 필터링 등을 수행하여 데이터의 특성과 인사이트를 도출할 수 있도록 한다.

```
┌─────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 멀티모달  │    │  정형     │    │  탐색적   │    │  모델    │    │  예측    │
│ 데이터    │ →  │  데이터   │ →  │  데이터   │ →  │  학습    │ →  │  추론    │
│ 수집     │    │  추출     │    │  분석     │    │  (ML)    │    │  실행    │
└─────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
  (3.01)         (3.03)        ▶ 본 문서       (3.05)          (3.05)
```

## 3.04.2 분석 기능 목록

| 기능 | 설명 | 구현 방식 |
|------|------|----------|
| **통계 요약** | 평균, 중앙값, 분산, 분위수, 왜도, 첨도 | 백엔드 집계 API + 프론트 카드 UI |
| **분포 시각화** | 히스토그램, 박스플롯, 밀도 곡선, 바이올린 플롯 | Chart.js / D3.js |
| **상관 분석** | 변수 간 상관계수 행렬(Pearson/Spearman), 산점도 | Heatmap + Scatter 차트 |
| **이상치 탐지** | IQR, Z-score, Isolation Forest, DBSCAN | 백엔드 분석 엔진 + 하이라이트 UI |
| **시계열 분석** | 추세, 계절성, 자기상관(ACF/PACF), 이동평균 | 시계열 라인 차트 + 분해 차트 |
| **필터링/그룹핑** | 다차원 조건 필터, 그룹별 집계, 피벗 테이블 | 인터랙티브 테이블 UI |
| **비교 분석** | 프로젝트/기간/버전/선박 간 비교 | Side-by-side 차트 |
| **데이터 프로파일링** | 컬럼별 자동 분석 (유형, 결측률, 고유값, 분포) | 자동 프로파일 리포트 |

### 핵심 인터랙션

| 인터랙션 | 동작 |
|---------|------|
| **컬럼 클릭** | 해당 컬럼의 분포 차트 자동 표시 |
| **셀 범위 드래그** | 선택 영역의 통계 요약 즉시 표시 |
| **차트 영역 브러싱** | 차트에서 범위 선택 → 테이블 자동 필터링 (양방향 연동) |

| **행 선택 + 우클릭** | 상세 보기, 원본 데이터로 이동, 이력 조회 |

## 3.04.4 분석 기능 상세 구현

### A. 통계 요약

```
┌───────────────────────────────────────────────┐
│               thickness (두께)                  │
├───────────────┬───────────────────────────────┤
│  건수          │  1,234                        │
│  평균          │  12.13 mm                     │
│  중앙값        │  12.30 mm                     │
│  표준편차      │  1.52 mm                      │
│  최소          │  8.70 mm  ⚠ 기준 미달          │
│  최대          │  15.20 mm                     │
│  Q1 (25%)     │  11.20 mm                     │
│  Q3 (75%)     │  13.10 mm                     │
│  결측          │  3건 (0.24%)                   │
└───────────────┴───────────────────────────────┘
```

**구현**: 백엔드에서 SQL 집계 쿼리 실행 → JSON 응답 → 프론트 카드 렌더링

### B. 이상치 탐지

| 방법 | 적용 조건 | 구현 |
|------|----------|------|
| **IQR** | 단변량, 빠른 탐지 | Q1-1.5*IQR ~ Q3+1.5*IQR 범위 밖 |
| **Z-score** | 정규분포 가정 | |z| > 3 기준 |
| **Isolation Forest** | 다변량, 복잡 패턴 | scikit-learn 백엔드 |
| **DBSCAN** | 밀도 기반 군집 외 이상치 | scikit-learn 백엔드 |

- 탐지된 이상치는 테이블·차트에서 **빨간색 하이라이트**
- 이상치 목록 별도 패널 + 원인 추정 가이드 표시
- 이상치 제외/포함 토글로 분석 결과 비교

### C. 시계열 분석

| 분석 | 설명 | 시각화 |
|------|------|--------|
| **추세 분석** | 장기 추세선 (이동평균, LOESS) | 원본 + 추세선 오버레이 |
| **계절성 분석** | STL 분해 (추세+계절+잔차) | 3단 분해 차트 |
| **자기상관** | ACF/PACF 플롯 | 막대 차트 + 유의 수준 |
| **변동성 분석** | 롤링 표준편차, 변동 계수 | 밴드 차트 |
| **이벤트 마커** | 검사일, 수리일 등 이벤트 시점 표시 | 수직선 마커 |

### D. 비교 분석

```
┌──────────────────────────────────────────────────────┐
│  비교 대상 설정                                        │
│  [기준] 선박 A - 2024.01 검사  vs  [비교] 선박 A - 2023.06 검사 │
├──────────────────────┬───────────────────────────────┤
│  Side-by-side 차트    │  차이 분석                      │
│  ┌────────┐┌────────┐│  ┌───────────────────────────┐ │
│  │ 2024.01││ 2023.06││  │ 변화량 히트맵              │ │
│  │ ██████ ││ ██████ ││  │ ■■■□□■■                   │ │
│  │ 두께분포││ 두께분포││  │ (빨강=감소, 파랑=증가)       │ │
│  └────────┘└────────┘│  └───────────────────────────┘ │
├──────────────────────┴───────────────────────────────┤
│  통계 비교: 평균 12.3→12.1 (▼-0.2), 최소 9.1→8.7 (▼-0.4) │
└──────────────────────────────────────────────────────┘
```

비교 축:
- **기간별**: 동일 대상의 시간에 따른 변화
- **버전별**: HullScan/Frame3D 버전 간 결과 차이
- **대상별**: 선박 A vs 선박 B 동일 조건 비교
- **프로젝트별**: 프로젝트 간 통계 비교

## 3.04.5 데이터 프로파일링 (자동 분석)

데이터셋 선택 시 **자동으로 전체 프로파일 리포트** 생성:

```
┌─────────────────────────────────────────────────┐
│  데이터 프로파일 리포트                             │
│  데이터셋: HullScan 측정 결과 (1,234건 x 12컬럼)   │
├─────────────────────────────────────────────────┤
│                                                 │
│  컬럼 요약                                       │
│  ┌────────┬───────┬───────┬───────┬──────────┐  │
│  │ 컬럼명  │ 유형   │ 결측률 │ 고유값 │ 분포      │  │
│  │ frame  │ string│ 0%    │ 120   │ ▁▃▅▇▅▃▁  │  │
│  │ thick  │ float │ 0.2%  │ 834   │ ▁▂▅▇▅▂▁  │  │
│  │ status │ enum  │ 0%    │ 3     │ OK:94% .. │  │
│  │ date   │ date  │ 0%    │ 45    │ 2023~2024 │  │
│  └────────┴───────┴───────┴───────┴──────────┘  │
│                                                 │
│  알림 사항                                       │
│  ⚠ thick 컬럼: 이상치 7건 (IQR 기준)              │
│  ⚠ frame 컬럼: 'F-012'에 값 집중 (편향)           │
│  ✅ 결측률 전체 0.1% 이하 (양호)                   │
└─────────────────────────────────────────────────┘
```

## 3.04.6 분석 결과 저장·공유

### 분석 세션 저장

```
AnalysisSession {
  id:           UUID
  name:         string           // "선박A 두께 분석 - 2024.06"
  dataset_id:   UUID             // 분석 대상 데이터셋
  filters:      JSONB            // 적용된 필터 조건
  charts:       JSONB            // 차트 설정 (유형, 축, 범위)
  layout:       JSONB            // 위젯 배치 레이아웃
  insights:     string[]         // 사용자가 기록한 인사이트
  shared_with:  UUID[]           // 공유 대상 사용자
  created_by:   UUID
  created_at:   timestamp
  updated_at:   timestamp
}
```

- **개인 저장**: 분석 상태 저장 → 나중에 이어서 작업
- **팀 공유**: 분석 세션 URL 공유 → 동일한 뷰로 확인
- **스냅샷**: 특정 시점의 분석 결과를 이미지/PDF로 캡처
- **인사이트 메모**: 차트에 메모/주석 추가 → 팀원과 공유

## 3.04.7 분석 결과 → 예측 모델 연계

분석 결과를 3.05(예측 모델 생성)으로 넘기는 연계 포인트:

```
분석 워크스페이스에서:
  1. "모델 학습용 데이터셋으로 내보내기" 클릭
  2. 선택된 필터/컬럼/전처리 적용된 데이터셋 생성
  3. 피처(독립변수) / 타겟(종속변수) 지정
  4. → 3.05 모델 학습 화면으로 이동 (데이터셋 자동 연결)
```

## 3.04.8 구현 기술 스택

| 구성 요소 | 기술 | 역할 |
|----------|------|------|
| **차트 엔진** | Recharts (React) 또는 Chart.js | 기본 차트 (라인/바/파이/산점도) |
| **고급 시각화** | D3.js | 히트맵, 바이올린, 커스텀 시각화 |
| **데이터 테이블** | TanStack Table (React Table) | 고성능 필터/정렬/페이지네이션 |
| **통계 엔진** | Python (pandas/scipy/statsmodels) | 서버 사이드 통계 계산 |
| **이상치 탐지** | scikit-learn (Isolation Forest 등) | 다변량 이상치 탐지 |
| **프로파일링** | ydata-profiling (구 pandas-profiling) | 자동 데이터 프로파일 |
| **레이아웃** | react-grid-layout | 드래그&드롭 대시보드 |
| **상태 관리** | React Query + Zustand | 분석 세션 상태 관리 |
