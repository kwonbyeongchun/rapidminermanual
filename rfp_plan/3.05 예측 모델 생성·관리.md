## 3.05.1 개요

축적된 정형 데이터를 학습 데이터로 활용하여 예측 모델을 생성하고, 모델 버전 관리·성능 추적·추론 실행까지 제공하는 ML 파이프라인을 구현한다.

```

└─────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### ① 데이터셋 구성

```
데이터셋 구성 화면:

1. 데이터 소스 선택
   └─ 3.04(EDA)에서 내보낸 정형 데이터셋 또는 직접 선택

2. 분할 비율 설정
   ├─ 학습(Train):    70% (기본)
   ├─ 검증(Validation): 15%
   └─ 테스트(Test):    15%

3. 분할 방식
   ├─ 랜덤 분할 (시드 고정으로 재현성 보장)
   ├─ 시간 기반 분할 (시계열: 과거=학습, 최근=테스트)
   └─ 계층 분할 (분류: 클래스 비율 유지)

4. 데이터셋 저장 → 버전 관리
   └─ 동일 데이터셋으로 여러 모델 비교 가능
```

### ② 피처 엔지니어링

| 기능 | 설명 | 구현 |
|------|------|------|
| **피처 선택** | 상관 분석 기반 중요 변수 선택 | 상관계수 + Feature Importance |
| **결측치 처리** | 평균/중앙값/최빈값 대체, 삭제 | 드롭다운 선택 |
| **정규화** | Min-Max, Standard, Robust 스케일링 | 드롭다운 선택 |
| **인코딩** | 범주형 → 숫자 (One-Hot, Label, Target) | 자동 감지 + 수동 선택 |
| **파생 변수** | 비율, 차이, 로그 변환, 다항식 | 수식 입력 UI |
| **시간 피처** | 요일, 월, 분기, 경과일 자동 생성 | 날짜 컬럼 감지 시 자동 |

### ⑤ 성능 평가

**회귀 모델 지표**:
| 지표 | 설명 | 목표 |
|------|------|------|
| RMSE | 평균 제곱근 오차 | 낮을수록 좋음 |
| MAE | 평균 절대 오차 | 낮을수록 좋음 |
| R² | 결정 계수 | 1에 가까울수록 좋음 |
| MAPE | 평균 절대 백분율 오차 | < 10% 권장 |

**분류 모델 지표**:
| 지표 | 설명 | 목표 |
|------|------|------|
| Accuracy | 정확도 | 높을수록 좋음 |
| Precision | 정밀도 | 클래스별 확인 |
| Recall | 재현율 | 클래스별 확인 |
| F1-Score | 정밀도·재현율 조화평균 | 높을수록 좋음 |

## 3.05.3 Model Registry (모델 레지스트리)

### 데이터 모델

```sql
CREATE TABLE ml_models (
  id               UUID PRIMARY KEY,
  name             VARCHAR(200) NOT NULL,
  description      TEXT,
  model_type       VARCHAR(50),          -- 'regression' | 'classification' | 'forecasting'
  algorithm        VARCHAR(100),         -- 'xgboost_regressor' | 'random_forest' | ...
  version          INTEGER NOT NULL,

  -- 학습 정보
  dataset_id       UUID,                 -- 학습 데이터셋 참조
  feature_columns  TEXT[],              -- 사용된 피처 목록
  target_column    VARCHAR(100),        -- 예측 대상 변수
  parameters       JSONB,               -- 하이퍼파라미터 전체
  training_config  JSONB,               -- 학습 설정 (분할 비율, 시드 등)

  -- 성능 지표
  metrics          JSONB,               -- {rmse, mae, r2, accuracy, f1, ...}
  training_time    FLOAT,              -- 학습 소요 시간 (초)

  -- 모델 아티팩트
  artifact_path    VARCHAR(500),        -- 직렬화된 모델 파일 경로 (Object Storage)
  artifact_size    BIGINT,             -- 모델 파일 크기

  -- 상태
  status           VARCHAR(20),         -- 'training' | 'ready' | 'deployed' | 'archived'
  deployed_at      TIMESTAMP,          -- 배포(활성화) 시점

  -- 메타
  created_by       UUID,
  created_at       TIMESTAMP DEFAULT NOW(),
  project_id       UUID,
  organization_id  UUID
);

-- 버전 관리 (같은 이름의 모델을 버전별 비교)
CREATE UNIQUE INDEX idx_model_version ON ml_models(name, version, project_id);
```

## 3.05.4 예측·추론 실행

### 추론 워크플로우

```
1. 사용자가 배포된 모델 선택
2. 신규 입력 데이터 지정
   ├─ 단건: 폼에 직접 값 입력
   ├─ 배치: CSV 업로드 또는 데이터셋 선택
   └─ 실시간: API 연동 (외부 시스템)
3. 예측 실행 → 작업 큐 등록 (3.06 연계)
4. 결과 출력
   ├─ 예측값 테이블
   ├─ 신뢰 구간 / 확률 표시
   └─ 원본 vs 예측 비교 차트
5. 결과 저장 + 이력 기록
```

## 3.05.5 예측 이력 관리

```sql
CREATE TABLE prediction_history (
  id               UUID PRIMARY KEY,
  model_id         UUID REFERENCES ml_models(id),
  model_version    INTEGER,
  input_data_id    UUID,                -- 입력 데이터 참조
  input_summary    JSONB,              -- 입력 요약 (건수, 기간 등)
  result_data_id   UUID,                -- 결과 데이터 참조
  result_summary   JSONB,              -- 결과 요약 (통계, 위험 건수 등)
  execution_time   FLOAT,              -- 실행 시간 (초)
  created_by       UUID,
  created_at       TIMESTAMP DEFAULT NOW(),
  project_id       UUID,
  organization_id  UUID
);
```

- 모든 예측 실행의 **입력·모델·결과**를 완전 기록
- 과거 예측과 실제 결과 비교 → **모델 정확도 사후 검증**
- 예측 이력 기반 모델 재학습 시점 판단 (성능 저하 감지)

## 3.05.6 모델 모니터링 (운영 후)

| 모니터링 항목 | 설명 | 알림 조건 |
|-------------|------|----------|
| **데이터 드리프트** | 입력 데이터 분포 변화 감지 | 학습 데이터 대비 분포 변화 > 임계값 |
| **성능 저하** | 예측 정확도 하락 추이 | RMSE 증가 > 20% 또는 R² 하락 > 0.1 |
| **추론 지연** | 예측 응답 시간 증가 | 평균 응답 > 5초 |
| **입력 이상** | 학습 범위 밖 입력 감지 | 입력값이 학습 데이터 범위 밖 |

성능 저하 감지 시 → 관리자 알림 + **재학습 권고** 자동 생성

## 3.05.7 구현 기술 스택

| 구성 요소 | 기술 | 역할 |
|----------|------|------|
| **ML 프레임워크** | scikit-learn, XGBoost, LightGBM | 전통 ML 모델 학습 |
| **딥러닝** | PyTorch / TensorFlow | LSTM, Autoencoder 등 |
| **시계열** | Prophet, statsmodels | ARIMA/Prophet 모델 |
| **실험 추적** | MLflow | 모델 레지스트리, 실험 추적, 모델 서빙 |
| **하이퍼파라미터 튜닝** | Optuna / scikit-learn GridSearchCV | 자동 최적화 |
| **모델 서빙** | MLflow Serving / FastAPI | 추론 API |
| **모니터링** | Evidently AI / 커스텀 | 데이터 드리프트, 성능 추적 |
| **학습 인프라** | Celery Worker (GPU 옵션) | 학습 작업 큐잉·실행 |
