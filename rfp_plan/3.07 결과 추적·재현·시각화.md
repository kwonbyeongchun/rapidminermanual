# 3.07 결과 추적·재현·시각화 - 구현 방법론

## 3.07.1 개요

모든 실행 결과의 이력 관리(입력/파라미터/버전/시간), 재현성 보장, 그래프·대시보드 시각화, 사용자 정의 분석 뷰를 구현한다.

---

## 3.07.2 결과 추적 체계

### 실행 결과 기록 구조

```
ExecutionRecord {
  id:               UUID
  job_id:           UUID              // 실행 작업 참조
  version_id:       UUID              // 버전 참조 (3.02)
  program_type:     string            // hullscan | frame3d | ...

  -- 재현성 보장을 위한 전체 컨텍스트
  input_snapshot: {
    files:          [{path, hash, size}]
    parameters:     JSONB
    environment:    {os, runtime_version, dependencies}
  }

  -- 결과
  output_snapshot: {
    files:          [{path, hash, size, type}]
    summary:        JSONB             // 핵심 지표 요약
  }

  -- 메타
  executed_by:      UUID
  executed_at:      timestamp
  duration_sec:     float
  status:           enum              // success | partial | failed
}
```

### 이력 추적 쿼리 예시

| 질문 | 추적 방법 |
|------|----------|
| "이 결과는 어떤 입력으로 나왔는가?" | execution_record → input_snapshot |
| "같은 입력으로 다시 실행하면 같은 결과인가?" | input_snapshot + environment로 재실행 |
| "v2와 v5의 결과 차이는?" | version_id 기준 결과 비교 |
| "지난 3개월 간 이 프로젝트의 결과 추이는?" | project_id + executed_at 필터 |
| "누가 이 파라미터를 변경했는가?" | version_history 감사 로그 |

## 3.07.3 재현성 보장 구현

### 재현성 3요소

```
┌───────────────────────────────────────┐
│             완전한 재현성               │
│                                       │
│  ① 동일 입력 데이터 (불변 스냅샷)       │
│       +                               │
│  ② 동일 파라미터 (config 스냅샷)        │
│       +                               │
│  ③ 동일 실행 환경 (컨테이너 이미지)      │
│       =                               │
│  ✓ 동일 결과 재현 가능                  │
└───────────────────────────────────────┘
```

### 구현 방법
1. **입력 불변성**: 원본 파일은 Content-Addressable Storage에 해시 기반 저장 (수정 불가)
2. **파라미터 스냅샷**: 실행 시점의 모든 설정을 JSONB로 저장 (이후 수정 영향 없음)
3. **환경 고정**: 프로그램별 Docker 이미지 태그 기록 → 동일 환경 재생성 가능
4. **재실행 버튼**: UI에서 과거 실행 선택 → "동일 조건으로 재실행" 1-click 제공

## 3.07.4 시각화 구현

### A. 결과 대시보드

```
┌─────────────────────────────────────────────────────────┐
│  프로젝트: 선박 A 선체 검사          기간: 2024.01~06     │
├─────────────────────────┬───────────────────────────────┤
│  KPI 카드                │  추세 차트                     │
│  ┌─────┐ ┌─────┐       │  ┌──────────────────────────┐ │
│  │평균  │ │최소  │       │  │   두께 변화 추이           │ │
│  │두께  │ │두께  │       │  │  ──/\──/\──              │ │
│  │12.3 │ │ 8.7 │       │  │        ──\──             │ │
│  └─────┘ └─────┘       │  └──────────────────────────┘ │
│  ┌─────┐ ┌─────┐       │  ┌──────────────────────────┐ │
│  │결함  │ │합격  │       │  │   결함 분포               │ │
│  │건수  │ │률   │       │  │  ██ █ ███ █              │ │
│  │ 23  │ │94.2%│       │  │  (히스토그램)              │ │
│  └─────┘ └─────┘       │  └──────────────────────────┘ │
├─────────────────────────┴───────────────────────────────┤
│  상세 결과 테이블 (정렬/필터/검색/페이지네이션)              │
│  Frame | 두께 | 기준 | 판정 | 변화량 | 비고                │
│  F-010 | 12.5 | 12.0 | OK  | -0.3  |                   │
│  F-011 | 11.8 | 12.0 | OK  | -0.5  |                   │
│  F-012 |  8.7 | 12.0 | NG  | -1.2  | ⚠ 기준 미달        │
└─────────────────────────────────────────────────────────┘
```

### B. 시각화 차트 유형

| 차트 유형 | 적용 대상 | 라이브러리 |
|----------|----------|----------|
| **라인 차트** | 시계열 추이, 버전별 변화 | Chart.js / Recharts |
| **바 차트** | 항목별 비교, 분포 | Chart.js / Recharts |
| **히트맵** | 위치별 두께/결함 분포 | D3.js |
| **산점도** | 변수 간 상관관계 | Chart.js |
| **박스플롯** | 분포, 이상치 | D3.js |
| **게이지** | KPI 달성률, 합격률 | Custom SVG |
| **테이블** | 상세 수치 데이터 | AG Grid / TanStack Table |

### C. 사용자 정의 시각화 뷰

```
1. 뷰 구성 화면:
   ├─ 차트 위젯 드래그&드롭 배치
   ├─ 각 위젯에 데이터 소스 + 변수 바인딩
   ├─ 필터 조건 설정 (프로젝트/기간/태그)
   └─ 레이아웃 저장 (개인용 / 팀 공유)

2. 위젯 유형:
   ├─ KPI 카드 (단일 수치 + 변화율)
   ├─ 차트 (라인/바/파이/산점도)
   ├─ 테이블 (필터/정렬 가능)
   ├─ 텍스트/마크다운 메모
   └─ 필터 컨트롤 (전역 필터 연동)

3. 데이터 갱신:
   ├─ 수동 새로고침
   └─ 자동 갱신 주기 설정 (1분/5분/30분)
```

## 3.07.5 데이터 내보내기

| 포맷 | 대상 | 구현 |
|------|------|------|
| **CSV** | 테이블 데이터 전체/선택 | 백엔드 스트리밍 생성 |
| **Excel** | 다중 시트 (결과 + 통계 + 설정) | ExcelJS / openpyxl |
| **PDF** | 대시보드 스냅샷, 보고서 | Puppeteer PDF 렌더링 |
| **JSON/API** | 외부 시스템 연계 | REST API 제공 |

### 내보내기 권한·이력 관리
- 다운로드 권한: 역할 기반 (관리자/권한 부여된 사용자만)
- 내보내기 이력: 누가/언제/무엇을/어떤 포맷으로 → 감사 로그 기록
- 민감 데이터 마스킹: 정책에 따라 특정 필드 마스킹 후 내보내기

## 3.07.6 구현 기술 스택

| 구성 요소 | 기술 | 역할 |
|----------|------|------|
| **차트** | Recharts (React) 또는 Chart.js | 기본 차트 렌더링 |
| **고급 시각화** | D3.js | 히트맵, 커스텀 시각화 |
| **대시보드 레이아웃** | react-grid-layout | 드래그&드롭 위젯 배치 |
| **데이터 테이블** | TanStack Table (React Table) | 고성능 테이블 렌더링 |
| **실시간 갱신** | WebSocket + React Query | 데이터 자동 갱신 |
| **PDF 생성** | Puppeteer / jsPDF | 대시보드 PDF 내보내기 |
