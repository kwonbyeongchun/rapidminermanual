## 공통 스타일 가이드

| 항목 | 설정 |
|------|------|
| **스타일** | 아이소메트릭 플랫 디자인 (Isometric Flat Design) |
| **배경** | 화이트 (#FFFFFF) |
| **메인 컬러** | 오션 블루 (#1A73E8), 네이비 (#0D47A1) |
| **보조 컬러** | 시안 (#00BCD4), 틸 (#009688), 골드 (#FFC107) |
| **해상도** | 1920x1080 또는 1:1 비율 (1024x1024) |
| **텍스트** | 이미지 내 텍스트 없음 (별도 캡션 처리) |
| **톤** | 전문적, 깔끔, 해양/엔지니어링 느낌 |
| **공통 요소** | 각 이미지에 선박/해양 맥락 요소 미세하게 포함 |
